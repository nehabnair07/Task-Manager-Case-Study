# Task Manager System

A Java-based Task Manager application developed as part of an Object-Oriented Programming (OOP) case study.  
The application allows users to create, manage, categorize, and track tasks efficiently through a simple user interface.

## Features

- Add tasks
- Delete tasks
- Update task details
- Mark tasks as completed
- View all tasks
- View pending/completed tasks 
- View tasks by category 

## OOP Concepts Used

- Encapsulation
- Composition
- Dependency 
- Association
- Aggregation

## Technologies Used

- Java
- Java FX

## How to Run

1. Open the project in Eclipse or any Java IDE
2. Compile the Java files
3. Run either:
   - `Main.java`
   - `TaskManagerUI.java`
